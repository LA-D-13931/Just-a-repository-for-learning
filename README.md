## 三、站点内容

### 每一节都包含

1. **承上启下段** —— `前置知识` 与 `本节要解决的问题`，说清"上一节留下什么、本节引入什么、后面在哪用"
2. **内容块分三层**（v0.7.0 起，见 `编排与文风规范.md` §一）——
   **主干**：💡 直观理解 / 📘 定义 / 📐 定理判定 / ⚙️ 计算步骤 / 例题 / 自测；
   **辅助**：⚠️ 易错点 / 🎯 考察要点 / 讲评（去描边、小字号）；
   **附录**：🔧 工程联系 / 🧭 教材映射（折叠成 `<details>`、默认收起、纯中文）
3. **例题** —— ≥2 道，其中 ≥1 道考研级，解答不跳步，每题自己验算过
4. **🎬 视频入口** —— 讲解区**只有一个，位于顶部**（`data-video-pos="top"`），见 §六
5. **自测** —— 7–9 题，中英对照，按 `基础 → 中等 → 考研` 自动重排，附讲评

> **🔗 知识关联不再是独立模块**（v0.7.2 起）：`.link-box` 已取消，内容改为三处就地融合 ——
> 承上写进「前置知识」段、启下写进「本节要解决的问题」末句、横向写在对应概念旁。
> 判据：一节正文里应能数出 **≥3 处带 §号的回指/前瞻**。`ch1.html` 的 10 个 `.link-box`
> 属**遗留待改**（见 `编排与文风规范.md` §六 第 1 项）。

### 双语：**整段对照**（中文段在前、英文段在后）

```html
<div class="bi">
  <p class="zh" lang="zh">中文第 1 段。</p>
  <p class="zh" lang="zh">中文第 2 段。</p>
  <p class="en" lang="en">English paragraph 1.</p>
  <p class="en" lang="en">English paragraph 2.</p>
</div>
```

**形式沿革**（三次都按用户反馈定的，别再改回去）：

| 版本 | 形式 | 结果 |
|---|---|---|
| v0.1 | 整段 `.zh` + `.en`（中文在前） | 可用 |
| v0.2 | 逐行 `.pair`（逐句交替） | ❌ 废弃 —— "太混乱了不好阅读" |
| v0.3 | 整段 `.en` + `.zh`（英文在前） | ❌ 废弃 —— 与 v0.1 顺序相反，两版并存导致施工方各写一半 |
| **v0.4** | **整段 `.zh` + `.en`（中文在前）** | ← **当前，全站唯一口径** |

中英**权重仍然相同**（英文段不降字号、不降颜色，只靠衬线体与左侧色条区分）。
`tests/theme.test.js` 会遍历所有 `.bi` 容器断言"首个段必须是 `.zh`"，改回英文在前会立刻失败。

**哪些地方不双语**（2026-09-16 收窄后）：

| 只要中文 | 理由 |
|---|---|
| `.warn-box` 易错点 | 用户要求 |
| `.exam-box` 考察要点 | 用户要求 |
| `.link-box` 知识关联（**已取消该模块**） | 用户要求 |
| `.map-note` 教材映射 | 用户要求 |
| `.app-box` 工程联系 · `.example` 例题 · `.q-review` 讲评 | 概念扩展应用 / 例题与错题讲解 |
| **首页 `index.html` 整页** | 用户要求「index 这个部分都不要英文」 |

> 上表是**内容层**的规定（这些块不写英文，且 `check-structure.py` 会**正向检查**
> 它们不含 `.en` —— 所以"给易错点补英文"是错误，不是加分）。
> 另有**显示层**的语言开关：中英对照 / 纯中文，见下。
| `.app-box` 工程联系 · `.example` 例题 · `.q-review` 讲评 | 概念扩展应用 / 例题讲解 |

口径见 `写作规范.md` §三·补六；术语见 `术语表.md`。

## 六、视频入口（v0.2.0 新增）

### 为什么做

原来站内虽然挂了视频，但入口埋在正文末尾的 `.video-link` 块里，**学生找不到**。

### 入口在哪

| 位置 | 形式 |
|---|---|
| 讲解区**顶部** | 🎬 **先看视频讲解** + 按钮组（**全节唯一入口**） |
| 首页章节卡片 | 🎬 视频讲解 N 个入口（点进章节页再精确定位） |

> ⚠️ **2026-09-16 用户要求删除讲解区底部的"看完还想听一遍？"卡片。**
> 现在规定：**每个小节只有一个视频入口，位于讲解区顶部**（`data-video-pos="top"`）。
> `check-bilingual.py` 会**正向断言"没有底部入口"**，写回 `data-video-pos="bottom"` 会报错。

### 点击深度

**首页 →（1 次）章节页 →（2 次）该节视频按钮 = 2 次点击。**
全站任何一节的视频入口都不超过 2 次点击，约定上限就是 2 次。

### 按钮规则

- **按钮样式**（不是普通文字链接）：图标 ▶ + 「视频讲解」+ 分 P 徽章 `P3` + 该 P 讲什么 + 外链标识 ↗
- **静态文档流布局**（`position: static`），绝不用 fixed/absolute 浮层 —— **不盖住正文、不遮挡公式**
- 所有按钮 `target="_blank"` + `rel="noopener noreferrer"`
- 视频**只外链，不嵌入、不转存**

### 不显示时长（有意为之）

规范原本要求按钮显示时长（如 `12:34`）。**本机与交接包里没有任何单集时长数据**，
只有两个合集的**总时长**（`BV1Eb411u7Fw` = 100:54:03、`BV1CAxaeHEeH` = 108:09:18）。
按"没有可靠数据源就不编造"的原则，**v0.2.0 不显示时长**，只显示分 P 号与该 P 的知识点。

将来拿到数据后，在 `assets/js/videos.js` 的对应条目加一个 `duration: '12:34'` 字段，
按钮会自动多显示一个时长胶囊——渲染器已支持，只差数据。

### ⚠️ 链接去重规则（同一知识点只留最新发布）

同一个知识点若有多个合集都讲了，**只保留最新发布的那一个**：
2024 年更新版（`BV1Eb411u7Fw`）比 2.0 版新，且覆盖更全（2.0 版缺傅里叶级数），
因此 **2.0 版不再挂入口**（仍留在 `videos.js` 的 `VIDEOS` 主表里备查）。
`tests/videos.test.js` 有一条断言守着这条规则，把 2.0 版挂回来会立刻失败。

### 分 P 号的核实状态

| 小节 | 分 P 号 | 状态 |
|---|---|---|
| `s1-1` | **p4 / p5 / p6** | ✅ 已核实（用户点开确认） |
| `s1-2` | **p7 / p8** | ✅ 已核实 |
| `s1-3` | **p10** | ✅ 已核实 |
| 其余各节 | 交接文档登记表 | ⚠️ `verified: false`，待核实 |

**⚠️ 交接文档有一处说错了**：它称 `BV1Eb411u7Fw`「无编号，只能按分 P 标题匹配」，
实测**分 P 编号正常**，`?p=4` 就是 1.1。已按实测改正。

只要某个小节里还有未核实的条目，按钮下方就会显示
「共 N 个视频入口，其中 M 个分 P 号待核实：点击后请以 B 站实际标题为准」。
核实一条就把对应的 `verified` 改成 `true`，该提示会自动消失。

### 无视频的小节

统一规则：**显示占位，不隐藏入口**（避免"有的地方空白、有的地方消失"）。
托马斯补充章（`tx1-1`、`tx1-2`）在宋浩合集里没有对应内容，会显示

## 七、中英整段对照

### 形式沿革

| 版本 | 形式 | 结果 |
|---|---|---|
| v0.1 | 整段 `.zh` + `.en`，中文在前 | 可用 |
| v0.2 | 逐行 `.pair`，英文行/中文行逐句交替 | ❌ 用户反馈"太混乱了不好阅读"，废弃 |
| v0.3 | 整段 `.en` + `.zh`，英文段在前 | ❌ 废弃 —— 规范与施工契约不一致，同一页出现两种顺序 |
| **v0.4** | **整段 `.zh` + `.en`，中文段在前** | ← **当前，全站唯一口径** |

**中英权重相同**这条从 v0.2 保留下来：英文段不降字号、不降颜色，
只靠衬线体与左侧色条区分。术语规则也不变：首次出现「中文（English）」，此后只用中文。
`tests/theme.test.js` 的【5】会遍历所有 `.bi` 容器断言"首个段必须是 `.zh`"。

### 自检

`python3 tests/check-bilingual.py` 会检查：

- 每个 `.bi` 容器里 `.en` 与 `.zh` 的**段数是否相等**
- **有无单侧语言**（只有英文段或只有中文段）
- **独立公式段（`$$…$$`）两侧是否逐字一致** —— 硬错误
- 行内公式是否互含（不满足的登记为待人工确认）
- **数字 / 节号**两侧是否对应（`§1.1`、`1.2–1.7` 等）—— 只提示、不阻断
- **纯中文模式无英文漏出**（模拟语言开关，剥离三种载体与 `.term-en` 后扫描可见文本）
- **视频入口**：每节恰好一个且在顶部

当前结果（v0.7.2 实测）：**对照段 243 条 · 段数不等 0 处 · 硬问题 0**；
**17 处 §号两侧不完全对应**属待人工确认项（多为英文写 `§1.6`、中文写 `1.5` 这类前缀差异；
其中 `s1-8` / `s1-9` 的定理编号偏移是真错，见 `对照偏差清单.md` D-11）。

### 已知的两类"不阻断差异"

1. **行内符号出现次数不同（11 处）** —— 英文写 `interval notation`、
   中文写 `$[a,b]$、$(a,b)$`，属行文差异。`check-bilingual.py` 会列出来供人工过目但不报错。
2. **`§` 前缀** —— 英文一律写 `§1.1`，中文在正文里常省略 `§`。同一节号，非不一致。

逐条的偏差与处置见 `对照偏差清单.md`。

### 已修：SVG 图解被误报成"未转义 `<`"（122 条假报 → 0）

v0.7.0 给 `s1-1` 加了两幅手写内联 SVG 后，`check-structure.py` 的"可疑标签"启发式
把 SVG 元素全部当成了"数学里的 `<` 没写成 `&lt;`"，**报出 122 条假问题**
（`<text>`43 `<path>`28 `<g>`26 `<circle>`14 `<svg>`4 `<ellipse>`3 `<defs>`2 `<marker>`2）。

**根因**：`ALLOWED_TAGS` 白名单里**没有任何 SVG 元素**。
**后果**：退出码恒为 1 且噪音淹没真问题；而"补 9 张图"正是下一步任务，
不加白名单每加一张图就多几十条假报。

**已修**（2026-09-16）：新增 `ALLOWED_SVG_TAGS` 白名单（`svg` `g` `path` `text` `circle` `ellipse`
`defs` `marker` `line` `rect` `polyline` `polygon` `tspan` `use` `linearGradient` 等）并并入 `ALLOWED_TAGS`。
实测：**122 条 → 0 条**，输出变为 `✓ 已建内容全部检查通过`。

> ⚠️ 白名单只挡"未转义 `<`"这一类误报。**SVG 里的两类真禁忌仍由 `check-html.py` 的
> 「内容卫生」把关**：SVG 内写 `$…$` 数学、写 Markdown `**加粗**`。

### `viz.js` 仍是线代专用

`assets/js/viz.js` 是原样复制过来的，**四个图形全部是线代内容**
（行列式面积、剪切不变面积、特征向量探索、单位圆→椭圆）。

**因此高数章节页目前没有写任何 `.viz`** —— 直接抄会渲染出与本课无关的线代图形。
要用可视化必须先扩充 `viz.js` 的图形类型。见 `写作规范.md` §三·补五。

### `.model-box` 样式缺失

线代站要求每节一个"典型模型题"块，但 `style.css` 里**没有** `.model-box` /
`.model-item` / `.model-signal` / `.model-route` 的样式，`check-structure.py` 也不检查。
高数站第 1 期**暂不启用**，套路型题目并入 `.example` + `.exam-box`。

### 站内导航仍是中文

顶栏、侧栏、章节导航的标签只写中文。原因：`.pair-en` 是块级元素，
嵌进 `<a>` 会让顶栏每项换行、1280px 下顶栏高度翻倍。
若要求导航也中英并列，需要先改导航的布局方案。

### 离线使用

MathJax 走 CDN。要完全离线：

```bash
# 1. 下载 MathJax 到本地
curl -o assets/vendor/tex-svg.js https://cdn.jsdelivr.net/npm/mathjax@3/es5/tex-svg.js
# 2. 把每个页面里的 CDN 地址换成本地路径
#    章节页：../assets/vendor/tex-svg.js   根目录页：assets/vendor/tex-svg.js
```

## 九、如何扩展内容

### 添加一个小节

1. **先改 `assets/js/site.js` 的 `COURSE` 数组**（加 `id` 与 `hours`）——
   首页进度统计、学时徽章、`check-structure.py` 的章节目录解析全都读这里，顺序反了会对不上。

3. 在对应 `chapters/chN.html` 里按 `写作规范.md` §一的骨架写 `h2` 与内容，
   别忘了 `data-video-map`，以及 `h2` 之后**唯一一个**顶部 `data-video-entry` 容器
   （**不要写底部入口**）。
4. 跑 `check-structure.py` + `check-bilingual.py` + `check-html.py`。

按 `写作规范.md` §三写 `.q`，必须带 `data-level`、`.q-stem-en`、`.q-explain`（含英文要点）。
`data-answer` 用 `|` 穷举合理写法。加完重跑 `quiz.test.js`。

### 改视频链接

只改 `assets/js/videos.js`。正文里没有任何 URL。
