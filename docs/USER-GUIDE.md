# 高数学习站 · 使用说明

可离线使用的高数学习软件，配套同济《高等数学》第八版全部内容（13 章 82 节 136 学时）。

## 一、安装与首次打开

双击安装包，一路「下一步」即可；免安装版放到任意文件夹双击就能用。

首次打开会有安全提示，属正常现象（软件未购买数字签名，不是病毒）：

- **Windows**：提示「已保护你的电脑」→ 点 **更多信息** → **仍要运行**。
- **macOS**：提示「无法验证开发者」→ **右键点图标 → 打开**，或到 **系统设置 → 隐私与安全性 → 仍要打开**。

## 二、界面介绍

- **顶部导航**：首页、公式速查表、综合自测卷、语言与配色开关。
- **左侧导航**：全部章节列表；下方是本页目录。
- **中间内容区**：讲解、例题、练习。
- **底部导航**：上一章 / 下一章。

## 三、主要功能

- **章节学习**：点左侧章名进入阅读，全部中英对照。
- **视频讲解**：点每节上方的蓝色按钮，**自动用浏览器打开**对应视频（需联网）。
- **例题与练习**：例题有完整步骤；练习题点选项作答，立即显示对错与解析。
- **已掌握**：每节标题右上角的勾选框，勾上后进度条与统计同步更新；进度存在本机，不会丢。
- **公式速查表 / 综合自测卷**：点顶部导航进入，前者查常用公式，后者做考研难度综合测试。
- **Desmos**：点顶部图标，在浏览器中打开在线图形计算器。
- **语言切换**：点顶部开关，中英文全文切换。

## 四、快捷操作

- **收起侧边栏**：点侧栏顶部按钮，收起后正文自动居中。
- **调整侧边栏宽度**：拖动侧栏右边缘，设置对所有章节生效。
- **显示异常**：先按刷新；仍不对就重启软件。

## 五、常见问题

**提示「已保护你的电脑」？** 点 **更多信息** → **仍要运行**。

**提示「无法验证开发者」？** 右键打开，或到 **隐私与安全性** 点 **仍要打开**。

**点视频没反应？** 视频在浏览器中打开，请确认已联网，并留意是否被拦截弹窗。

**第一次打开很慢？** 首次需解压运行环境，属正常，之后会明显加快。

**公式乱码？** 请截图并说明章节，反馈给分享者。
