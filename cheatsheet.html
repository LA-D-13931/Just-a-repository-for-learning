1-1 定义域与函数的四种特性 / Domains and Function Properties

求定义域就是"把使表达式有意义的全部限制取交集"；下面一张表列全五种限制。

限制条件例
分式分母 $\ne 0$$\dfrac{1}{x-3}$ 要求 $x \ne 3$
偶次根式被开方式 $\ge 0$$\sqrt{4-x^2}$ 要求 $4-x^2 \ge 0$
对数真数 $> 0$；真数落在分母上时还要 $\ne 1$（因 $\ln 1 = 0$）$\dfrac{1}{\ln(x+1)}$ 要求 $x+1 > 0$ 且 $x+1 \ne 1$
反三角函数$\arcsin u$、$\arccos u$ 要求 $-1 \le u \le 1$$\arcsin(x-1)$ 要求 $0 \le x \le 2$
正切$u \ne \dfrac{\pi}{2} + k\pi$（$k \in \mathbb{Z}$）$\tan 2x$ 要求 $x \ne \dfrac{\pi}{4} + \dfrac{k\pi}{2}$

把每条限制解成 $x$ 的区间后取交集；交集为空，说明该表达式不表示函数。

特性定义要点
有界性存在 $M > 0$，使对一切 $x \in D$ 都有 $|f(x)| \le M$对区间而言：$\dfrac{1}{x}$ 在 $(0,1)$ 上无界，在 $[1,+\infty)$ 上有界
单调性$x_1 < x_2 \Rightarrow f(x_1) < f(x_2)$ 为单调增加；不等号反向为单调减少与有界性合起来通向 $1\!-\!6$ 的单调有界准则
奇偶性$D$ 关于原点对称；$f(-x)=f(x)$ 为偶函数，$f(-x)=-f(x)$ 为奇函数定义域不对称就谈不上奇偶
周期性存在 $T > 0$，使 $x+T \in D$ 且 $f(x+T)=f(x)$常数函数是周期函数，但没有最小正周期

1-2 数列的极限 / Limits of Sequences

数列极限只有一条定义、三条性质与一组运算法则；查定义看这里，查运算看末行。

📘定义　数列的极限（$\varepsilon$-$N$ 定义）

对任意给定的正数 $\varepsilon$，总存在正整数 $N$，使得当 $n > N$ 时不等式 $|a_n-a| < \varepsilon$ 恒成立，则称 $a$ 是数列 $\{a_n\}$ 的极限，记作

$$\forall \varepsilon > 0,\ \exists N \in \mathbb{N}_+,\ \forall n > N:\ |a_n-a| < \varepsilon$$

几何含义：$a_n$ 从第 $N+1$ 项起全部落入开区间 $(a-\varepsilon, a+\varepsilon)$，只有前有限项可能落在外面。

性质结论用法
唯一性收敛数列的极限唯一反证：两个不同的数不可能同时被任意窄的区间套住
有界性收敛数列一定有界逆否：无界数列一定发散
保号性若 $a > 0$（或 $a < 0$），则从某项起 $a_n > 0$（或 $a_n < 0$）只管"从某项起"；由 $a_n > 0$ 只能推出 $a \ge 0$

四则运算（前提：两个极限各自存在）：

$$\lim_{n\to\infty}(a_n \pm b_n)=a \pm b,\qquad \lim_{n\to\infty}(a_n b_n)=a b,\qquad \lim_{n\to\infty}\frac{a_n}{b_n}=\frac{a}{b}\quad (b \ne 0)$$

1-3 函数的极限 / Limits of Functions

函数极限有两种过程：$x \to \infty$ 管远处，$x \to x_0$ 管近处；判存在性用左右极限。

📘定义　$x\to\infty$ 与 $x\to x_0$ 时函数的极限

$$\lim_{x\to\infty} f(x) = A \iff \forall \varepsilon > 0,\ \exists X > 0:\ |x| > X \Rightarrow |f(x)-A| < \varepsilon$$

$$\lim_{x\to x_0} f(x) = A \iff \forall \varepsilon > 0,\ \exists \delta > 0:\ 0 < |x-x_0| < \delta \Rightarrow |f(x)-A| < \varepsilon$$

第二种里的 $0 < |x-x_0|$ 把 $x=x_0$ 排除在外，这正是"极限与 $f(x_0)$ 无关"的写法来源；$\delta$ 一般依赖于 $\varepsilon$。

结论内容备注
左右极限判据$\lim\limits_{x\to x_0} f(x) = A \iff \lim\limits_{x\to x_0^-} f(x) = \lim\limits_{x\to x_0^+} f(x) = A$一侧不存在，或两侧存在但不等，则极限不存在
局部有界性若 $\lim\limits_{x\to x_0} f(x) = A$，则存在 $\delta > 0$ 与 $M > 0$，使 $0 < |x-x_0| < \delta$ 时 $|f(x)| \le M$局部性质，只保证 $x_0$ 附近有界；反向不成立
水平渐近线$\lim\limits_{x\to\infty} f(x) = A$ 的几何含义是：直线 $y=A$ 是曲线的水平渐近线曲线落在 $y=A\pm\varepsilon$ 之间，只在图形最左、最右两端要求成立

1-4 无穷小与无穷大 / Infinitesimals and Infinity

两者都是过程量，不是数；本节四条结论把"趋于 0"翻译成可以加减乘除的写法。

对象定义要点
无穷小在给定过程中 $\lim f(x) = 0$是变量不是数；$0$ 是唯一的常数无穷小；数列情形即 $\lim\limits_{n\to\infty} a_n = 0$
无穷大对任意 $M > 0$，总存在 $\delta > 0$，使 $0 < |x-x_0| < \delta$ 时 $|f(x)| > M$，记作 $\lim\limits_{x\to x_0} f(x) = \infty$$\infty$ 不是数，此式表示极限不存在；要区分符号时写 $+\infty$ 或 $-\infty$
结论内容
无穷小与无穷大的互推同一过程中：$f$ 是无穷大 $\Rightarrow \dfrac{1}{f}$ 是无穷小；$f$ 是无穷小且 $f \ne 0$ $\Rightarrow \dfrac{1}{f}$ 是无穷大
极限与无穷小的关系$\lim f(x) = A \iff f(x) = A + \alpha(x)$，其中 $\alpha(x)$ 是同一过程中的无穷小；等价写法 $f(x) \to A \iff f(x)-A \to 0$
无穷小 $\times$ 有界$\alpha$ 是无穷小，$g$ 在 $x_0$ 的某去心邻域内有界 $\Rightarrow \alpha g$ 是无穷小
两条推论常数 $\times$ 无穷小 $=$ 无穷小；有限个无穷小之积 $=$ 无穷小

1-5 极限运算法则 / Limit Laws

四则运算的前提是各极限都存在且有限，商的公式还要分母极限非零；换元法多一条"内层取不到 $u_0$"。

$$\lim_{x\to x_0}[f(x) \pm g(x)] = A \pm B,\qquad \lim_{x\to x_0}[f(x)\,g(x)] = A\,B,\qquad \lim_{x\to x_0}\frac{f(x)}{g(x)} = \frac{A}{B}\quad (B \ne 0)$$

法则内容前提
和、差、积见上式前两条只要求两个极限都存在（有限）
商见上式第三条还要 $B \ne 0$；$B=0$ 时法则失效，须另行讨论
常数因子与幂$\lim\limits_{x\to x_0}[c\,f(x)] = c\,A$；$\lim\limits_{x\to x_0}[f(x)]^n = A^n$$c$ 为常数，$n$ 为正整数
幂函数$\lim\limits_{x\to x_0} x^n = x_0^n$代入法的起点
复合函数（换元）$\lim\limits_{x\to x_0} g(x) = u_0$，存在去心邻域使 $g(x) \ne u_0$，且 $\lim\limits_{u\to u_0} f(u) = A$ $\Rightarrow$ $\lim\limits_{x\to x_0} f[g(x)] = A$三个条件缺一不可
连续时退化$f$ 在 $u_0$ 连续时，$\lim\limits_{x\to x_0} f[g(x)] = f(u_0)$连续函数可以穿过极限号

1-6 极限存在准则与两个重要极限 / Existence Criteria and Two Important Limits

两个准则负责"证明极限存在"，两个重要极限负责"算出具体值"。

准则条件结论
夹逼准则（数列）存在 $N_0 > 0$，当 $n > N_0$ 时 $y_n \le x_n \le z_n$；且 $\lim\limits_{n\to\infty} y_n = \lim\limits_{n\to\infty} z_n = a$$\lim\limits_{n\to\infty} x_n = a$
夹逼准则（函数）$x_0$ 的某去心邻域内 $g(x) \le f(x) \le h(x)$，且同一过程下 $\lim g(x) = \lim h(x) = A$$\lim f(x) = A$
单调有界准则单调增加且有上界；或单调减少且有下界数列收敛（只给存在性，不给极限值）
等价说法单调数列收敛 $\iff$ 有界
名称公式通用形式
第一重要极限（$x$ 取弧度）$\lim\limits_{x\to0}\dfrac{\sin x}{x} = 1$$\lim\limits_{x\to0}\dfrac{\sin \square}{\square} = 1$，分子分母的方框逐字相同，且方框本身趋于 $0$
第二重要极限$\lim\limits_{x\to\infty}\left(1+\frac{1}{x}\right)^x = e$$\lim\limits_{u\to0}(1+u)^{\frac{1}{u}} = e$；数列版 $\lim\limits_{n\to\infty}\left(1+\frac{1}{n}\right)^n = e$

$1^\infty$ 型速记：若 $u \to 0$、$v \to \infty$ 且 $uv \to A$，则 $(1+u)^v \to e^A$。常数 $e = 2.718281828\ldots$。识别信号是"底数趋于 $1$、指数趋于 $\infty$"，此时不能把底数与指数分开取极限。

1-7 无穷小的比较与等价无穷小表 / Comparison of Infinitesimals

比较两个无穷小趋于零的快慢；等价替换只在乘除的因子位置上可用。

$\lim \dfrac{\beta}{\alpha}$结论记号
$0$$\beta$ 是比 $\alpha$ 高阶的无穷小，$\alpha$ 是比 $\beta$ 低阶的无穷小$\beta = o(\alpha)$
$c \ne 0$$\beta$ 与 $\alpha$ 是同阶无穷小$\beta = O(\alpha)$
$1$$\beta$ 与 $\alpha$ 是等价无穷小$\beta \sim \alpha$
$\infty$$\beta$ 是比 $\alpha$ 低阶的无穷小$\beta = o^{-1}(\alpha)$

$k$ 阶无穷小：若 $\lim\limits_{x\to0}\dfrac{\beta}{x^k} = c \ne 0$（$k > 0$），则 $\beta$ 是 $k$ 阶无穷小——它是拿 $x^k$ 当尺子量出来的结论。若该极限为 $0$，只能说阶数大于 $k$，不能说等于 $k$。

📐定理　等价无穷小替换（乘除可换，加减不可换）

同一过程中 $\alpha \sim \alpha'$、$\beta \sim \beta'$，且 $\lim \dfrac{\beta'}{\alpha'}$ 存在（或为 $\infty$），则

$$\lim \frac{\beta}{\alpha} = \lim \frac{\beta'}{\alpha'};\qquad \lim \beta\alpha = \lim \beta'\alpha'.$$

严格含义是 $\beta = \alpha + o(\alpha)$。乘、除、乘方、开方的因子位置可以整体替换；加减法中最高阶项可能相消，替换没有同等保证。

当 $x \to 0$ 时等价关系阶数
$\sin x$$\sin x \sim x$1 阶
$\tan x$$\tan x \sim x$1 阶
$\arcsin x$$\arcsin x \sim x$1 阶
$\arctan x$$\arctan x \sim x$1 阶
$\ln(1+x)$$\ln(1+x) \sim x$1 阶
$e^x-1$$e^x-1 \sim x$1 阶
$(1+x)^a-1$$(1+x)^a-1 \sim ax$1 阶
$1-\cos x$$1-\cos x \sim \dfrac{x^2}{2}$2 阶

表中 $\arctan x \sim x$ 不在正文的等价表内，由 $\tan x \sim x$ 经反函数换元得到，此处一并列出。整张表只在 $x \to 0$ 时成立；遇 $x \to \infty$ 先令 $t = \dfrac{1}{x}$ 化到 $t \to 0$。

1-8 函数的连续性与间断点 / Continuity and Discontinuities

连续的判据只有一条：极限值等于函数值；间断点按左右极限是否存在分两类。

表述内容
极限式$\lim\limits_{x\to x_0} f(x) = f(x_0)$（要求极限存在，且等于函数值）
增量式记 $\Delta y = f(x_0+\Delta x)-f(x_0)$，则 $\lim\limits_{\Delta x\to0} \Delta y = 0$
单侧式$\lim\limits_{x\to x_0^-} f(x) = \lim\limits_{x\to x_0^+} f(x) = f(x_0)$，即既左连续又右连续

区间上的连续：$f$ 在 $(a,b)$ 内每一点连续，则称在 $(a,b)$ 内连续；若还有 $f$ 在 $a$ 处右连续、在 $b$ 处左连续，则称在闭区间 $[a,b]$ 上连续。

类型条件子类
第一类间断点$f(x_0^-)$ 与 $f(x_0^+)$ 都存在两者相等为可去间断点；两者不等为跳跃间断点，$|f(x_0^+)-f(x_0^-)|$ 称为跳跃度
第二类间断点$f(x_0^-)$ 与 $f(x_0^+)$ 中至少有一个不存在一侧极限为无穷大：无穷间断点；函数值无限次振荡：振荡间断点

1-9 初等函数的连续性 / Continuity of Elementary Functions

本节的用处只有一个：把一大类极限题从"算"降级成"代"。

结论内容
四则运算$f$、$g$ 在 $x_0$ 连续 $\Rightarrow$ $f+g$、$f-g$、$f \cdot g$ 在 $x_0$ 连续；若又有 $g(x_0) \ne 0$，则 $\dfrac{f}{g}$ 在 $x_0$ 连续
复合$u=g(x)$ 在 $x_0$ 连续、$y=f(u)$ 在 $u_0=g(x_0)$ 连续 $\Rightarrow$ $f[g(x)]$ 在 $x_0$ 连续
反函数$y=f(x)$ 在区间 $I_x$ 上单调且连续 $\Rightarrow$ 反函数在对应区间 $I_y$ 上单调且连续
初等函数基本初等函数在它们的定义域内连续；一切初等函数在其定义区间内连续
用法定义区间内求极限即代入：$\lim\limits_{x\to x_0} f(x) = f(x_0)$

1-10 闭区间上连续函数的性质 / Properties on a Closed Interval

四个定理都建立在"闭区间 + 连续"上，结论只保证存在。

定理条件结论
最值定理$f$ 在闭区间 $[a,b]$ 上连续必取到最大值 $M$ 与最小值 $m$：存在 $\xi_1,\xi_2 \in [a,b]$，使 $m = f(\xi_1) \le f(x) \le f(\xi_2) = M$
有界性定理同上存在 $K > 0$，使一切 $x \in [a,b]$ 有 $|f(x)| \le K$（最值定理的推论，$K=\max\{|m|,|M|\}$）
介值定理$f$ 在 $[a,b]$ 上连续，$m$、$M$ 为其最值对任意 $\mu \in [m,M]$，至少存在一点 $\xi \in [a,b]$ 使 $f(\xi) = \mu$
零点定理$f$ 在 $[a,b]$ 上连续，且 $f(a)f(b) < 0$至少存在一点 $\xi \in (a,b)$ 使 $f(\xi) = 0$，即方程 $f(x)=0$ 在 $(a,b)$ 内至少有一个实根

两者都不给位置与个数：要谈根的个数，必须再加上单调性之类的条件。

2-1 导数概念与可导性 / The Derivative as a Limit

导数是差商的极限；判分段点可导性只能靠左右导数。

📘定义　导数

设 $\Delta y = f(x_0+\Delta x)-f(x_0)$，若极限

$$f'(x_0)=\lim_{\Delta x \to 0}\frac{\Delta y}{\Delta x}=\lim_{\Delta x \to 0}\frac{f(x_0+\Delta x)-f(x_0)}{\Delta x}$$

存在，则称 $f$ 在点 $x_0$ 可导，此极限为 $f$ 在 $x_0$ 的导数。比值 $\dfrac{\Delta y}{\Delta x}$ 称为差商。三种记法都要认得：

$$f'(x_0),\qquad y'\big|_{x=x_0},\qquad \left.\frac{\mathrm{d}y}{\mathrm{d}x}\right|_{x=x_0}$$

结论内容
单侧导数$f'_-(x_0)=\lim\limits_{\Delta x \to 0^-}\dfrac{f(x_0+\Delta x)-f(x_0)}{\Delta x}$，$f'_+(x_0)$ 同式取 $\Delta x \to 0^+$
可导的充要条件$f'_-(x_0)$ 与 $f'_+(x_0)$ 都存在且相等，此时 $f'(x_0)=f'_-(x_0)=f'_+(x_0)$
可导必连续$f$ 在 $x_0$ 可导 $\Rightarrow$ $f$ 在 $x_0$ 连续；反之不成立，$y=|x|$ 在 $x=0$ 连续但不可导
几何意义$f'(x_0)$ 是曲线 $y=f(x)$ 在点 $(x_0,f(x_0))$ 处切线的斜率；可导意味着切线不垂直于 $x$ 轴

2-3 高阶导数与莱布尼茨公式 / Higher-Order Derivatives

求 $n$ 阶导数有三条路线：逐次求导、用常用函数的 $n$ 阶公式、用莱布尼茨公式。

📘定义　高阶导数

$$f''(x)=\lim_{\Delta x\to0}\frac{f'(x+\Delta x)-f'(x)}{\Delta x},\qquad f^{(n)}(x)=\left[f^{(n-1)}(x)\right]'$$

约定 $f^{(0)}(x)=f(x)$、$f^{(1)}(x)=f'(x)$。括号里的 $(n)$ 是求导阶数，不是幂，$f^{(2)}(x)$ 与 $[f(x)]^2$ 是两回事。

函数$n$ 阶导数
$x^{\mu}$$\mu(\mu-1)\cdots(\mu-n+1)x^{\mu-n}$
$x^{m}$（$m$ 为正整数）$(x^{m})^{(n)}=\dfrac{m!}{(m-n)!}x^{m-n}$（$n \le m$）；当 $n > m$ 时 $(x^{m})^{(n)}=0$
$e^{ax}$$(e^{ax})^{(n)}=a^{n}e^{ax}$，取 $a=1$ 即 $(e^{x})^{(n)}=e^{x}$
$\sin x$$(\sin x)^{(n)}=\sin\left(x+\dfrac{n\pi}{2}\right)$
$\cos x$$(\cos x)^{(n)}=\cos\left(x+\dfrac{n\pi}{2}\right)$
$\ln x$$(\ln x)^{(n)}=\dfrac{(-1)^{n-1}(n-1)!}{x^{n}}$（$x > 0$，$n \ge 1$）
$\dfrac{1}{x}$$\left(\dfrac{1}{x}\right)^{(n)}=\dfrac{(-1)^{n}n!}{x^{n+1}}$
$\dfrac{1}{ax+b}$$\left(\dfrac{1}{ax+b}\right)^{(n)}=\dfrac{(-1)^{n}n!\,a^{n}}{(ax+b)^{n+1}}$
$a^{x}$$(a^{x})^{(n)}=a^{x}(\ln a)^{n}$（$a > 0$，$a \ne 1$）

莱布尼茨公式（$u$、$v$ 都有 $n$ 阶导数，$u^{(0)}=u$、$v^{(0)}=v$）：

$$(uv)^{(n)}=\sum_{k=0}^{n}\binom{n}{k}u^{(k)}v^{(n-k)},\qquad \binom{n}{k}=\frac{n!}{k!(n-k)!}$$

展开即 $(uv)^{(n)}=u^{(n)}v+nu^{(n-1)}v'+\dfrac{n(n-1)}{2}u^{(n-2)}v''+\cdots+uv^{(n)}$。通常把多项式取作 $v$：$v$ 是 $m$ 次多项式时，和式只剩 $m+1$ 项。

2-4 隐函数、对数求导、参数方程与相关变化率 / Implicit, Logarithmic, Parametric and Related Rates

四种题型的固定做法集中在这一节；共同点是"把 $y$ 看成 $x$（或 $t$）的函数"。

题型公式 / 步骤前提
隐函数求导$\dfrac{dy}{dx} = -\dfrac{F_x}{F_y}$；也可把 $y$ 看成 $x$ 的函数，方程 $F(x,y)=0$ 两边对 $x$ 求导，$y'$ 的系数即 $F_y$$F_y \ne 0$（曲线在该点不竖直）
对数求导法① 在 $f(x) \ne 0$ 处两边取对数（$y$ 可能取负值时写 $\ln|y|$）；② 用对数性质把右边拆成和、差与常数倍；③ 两边对 $x$ 求导，左边得 $\dfrac{y'}{y}$；④ 乘回 $y$ 并回代原式适用于幂指函数（如 $x^{\sin x}$）与连乘连除式
参数方程一阶导$\dfrac{dy}{dx} = \dfrac{\psi'(t)}{\varphi'(t)} = \dfrac{dy/dt}{dx/dt}$$x=\varphi(t)$、$y=\psi(t)$ 可导，$\varphi'(t) \ne 0$
参数方程二阶导$\dfrac{d^{2}y}{dx^{2}} = \dfrac{1}{\varphi'(t)} \cdot \dfrac{d}{dt}\left(\dfrac{\psi'(t)}{\varphi'(t)}\right)$先把 $\dfrac{dy}{dx}$ 看成 $t$ 的函数求导，再除以 $\dfrac{dx}{dt}$
相关变化率① 把随时间变化的量设成 $t$ 的函数；② 写出联系它们的方程，先把常量代入；③ 两边对 $t$ 求导，如 $\dfrac{dV}{dt} = \dfrac{dV}{dh} \cdot \dfrac{dh}{dt}$；④ 代入瞬时值求解并核对符号先求导后代入数值；随时间变化的量不可提前代入

2-5 微分与近似计算 / Differentials and Linear Approximation

微分是增量的线性主部：把 $\Delta y$ 换成一个算得出来的 $f'(x_0)\Delta x$。

📘定义　可微与微分

若 $\Delta y = f(x_0+\Delta x)-f(x_0)$ 可表示为

$$\Delta y = A\,\Delta x + o(\Delta x)\qquad (\Delta x \to 0),$$

其中 $A$ 是不依赖于 $\Delta x$ 的常数，$o(\Delta x)$ 是比 $\Delta x$ 高阶的无穷小，则称 $f$ 在 $x_0$ 可微，$A\,\Delta x$ 称为微分，记作 $dy = A\,\Delta x$。规定自变量的微分 $dx = \Delta x$。

结论内容
可微 $\iff$ 可导$f$ 在 $x_0$ 可微的充要条件是 $f$ 在 $x_0$ 可导，此时 $A$ 唯一确定且 $A=f'(x_0)$
微分公式$dy = f'(x_0)\,dx$；一般点处 $dy = f'(x)\,dx$；$u$ 为中间变量时 $dy = f'(u)\,du$
近似计算$|\Delta x|$ 很小时 $f(x_0+\Delta x) \approx f(x_0)+f'(x_0)\Delta x$
线性主部$dy$ 是 $\Delta y$ 的线性主部；$dy \ne \Delta y$，两者相差 $o(\Delta x)$，而 $dx = \Delta x$ 只对自变量成立
微分法则公式
常数、常数倍$d(C)=0$；$d(Cu)=C\,du$
和、差$d(u \pm v)=du \pm dv$
积、商$d(uv)=u\,dv+v\,du$；$d\left(\dfrac{u}{v}\right)=\dfrac{v\,du-u\,dv}{v^{2}}$（$v \ne 0$）
幂$d(x^{\mu})=\mu x^{\mu-1}dx$
三角$d(\sin x)=\cos x\,dx$；$d(\cos x)=-\sin x\,dx$；$d(\tan x)=\sec^{2}x\,dx$
指、对$d(e^{x})=e^{x}dx$；$d(\ln x)=\dfrac{1}{x}dx$（$x > 0$）
反三角$d(\arcsin x)=\dfrac{1}{\sqrt{1-x^{2}}}dx$（$|x| < 1$）

TX1 视窗与方形视窗 / Viewing Windows

判断软件画出的图形是否与真实形状一致，只用一个比例条件。

概念内容
视窗作图时显示的矩形区域，记作 $[a,b] \times [c,d]$，即 $a \le x \le b$ 且 $c \le y \le d$；默认视窗由软件选定，与函数的真实范围无关
方形视窗两轴单位长度相同：$x$ 轴上 1 个单位的图上长度等于 $y$ 轴上 1 个单位的图上长度。它不指显示区本身是正方形
真实比例条件显示区可作图部分的像素宽为 $W$、高为 $H$ 时，视窗是方形视窗 $\iff$ $\dfrac{b-a}{d-c} = \dfrac{W}{H}$
失真因子$k = \dfrac{W(d-c)}{H(b-a)}$；显示出的斜率等于真实斜率除以 $k$，长度按同一因子拉伸，$k \ne 1$ 时角度与形状都不可信
固定 $y$ 范围要把 $y$ 范围固定为 $[c,d]$ 而让视窗成为方形，取 $b-a = (d-c)\dfrac{W}{H}$
采样软件在 $[a,b]$ 内取等距 $x$ 值，只画落在定义域内且 $f(x) \in [c,d]$ 的点，再把相邻已画点用短线段连接

三条推论：视窗之外的部分被裁掉；连线是画出来的，不是算出来的；采样点之间的极值、间断与振荡软件没有数据，只能由相邻点去猜。选视窗的顺序是"先解析、后图形"。

TX2 变化率与导数的单位 / Rates of Change and Units

导数就是瞬时变化率；单位永远是"因变量单位 / 自变量单位"。

对象公式说明
平均变化率$\dfrac{\Delta y}{\Delta x} = \dfrac{f(x_0+\Delta x)-f(x_0)}{\Delta x}$区间上的量，就是差商，任何函数都有
瞬时变化率$f'(x_0) = \lim\limits_{\Delta x\to0}\dfrac{f(x_0+\Delta x)-f(x_0)}{\Delta x}$点上的量，要求 $f$ 在 $x_0$ 可导
单位$\dfrac{\Delta y}{\Delta x}$ 与 $f'(x_0)$ 的单位都是"因变量单位 / 自变量单位"位移以 m 计、时间以 s 计，则 $s'(t)$ 的单位是 m/s；温度场 K 对半径 m 求导，单位是 K/m
物理意义$s'(t_0)$ 是 $t_0$ 时刻的瞬时速度；$a(t) = v'(t) = s''(t)$ 是加速度对速度再求导得加速度
可导与单侧变化率$f'(x_0)$ 存在 $\iff$ $f'_-(x_0)$ 与 $f'_+(x_0)$ 都存在且相等可导强于连续；$|x|$ 在 $x_0=0$ 处连续但左右差商极限不同
